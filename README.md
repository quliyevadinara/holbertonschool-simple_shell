# Simple Shell

A simple UNIX command line interpreter created as a project for Holberton School.

## Description

This is a simple shell program that can execute commands, handle the PATH, and implement basic built-ins like `exit` and `env`.

## Features

- Display a prompt and execute commands
- Handle command lines with arguments
- Search for executables using PATH
- Implement `exit` and `env` built-ins
- Handle errors and end-of-file condition (Ctrl+D)
